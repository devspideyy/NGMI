# NGMI — Viral hooks

Every hook is built to make a **15-second clip** someone posts.

| Hook | What it is | Build notes |
| --- | --- | --- |
| **Rating Card** | After every run, a 9:16 share image: "Kevin – 3.2/10 – killed by a Double Chin" | Render-target screenshot + UI overlay; save PNG to disk; "Copy" button |
| **Mog Cam** | One key saves the last 30 s as a clip; funny deaths auto-tagged | Use a replay/recording plugin or NVIDIA/OS capture hooks; keep local |
| **Streamer Chat Mode** | Twitch/Kick chat votes on a horror event every 60 s ("spawn Front Camera", "lights off") | Twitch IRC/EventSub; Kick API if available. Opt-in, streamer-controlled |
| **Mic mode** | Mouth Breathers hear the player's real voice | Local mic amplitude only; **never record or upload audio**; opt-in |
| **"TOO MUCH BONE"** | Clavicoolar's headshot-immunity gag: slow-mo + ping sound | Signature moment; make it loud and readable |
| **Chico sightings** | 1-in-50 cryptid spawn; screenshot for a badge | Out-of-focus "Bigfoot photo" look; community "I SAW CHICO" moments |
| **Touch Grass ending** | Secret: leave in the first 60 s → credits roll | Word-of-mouth secret |
| **Daily Face** | One global modifier per day | Gives streamers a daily reason to play |

Measure: clips shared per 100 runs, streamer mode sessions, wishlist conversions from clips.
